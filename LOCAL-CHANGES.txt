The original WASM is retained. The entry page loads a separately named patched
WASM with a matching SHA-384 integrity attribute, avoiding stale asset caches.
The homepage (916) and logo factory (20386) are changed; two widget destructor

for compatibility with optimized callers. Removed elements use Rust vtables, and
vector lengths are updated so layout, hit testing and focus exclude them.
Narrow layouts retain Recent and Welcome tabs. The rest of the drawing code
and the user's existing files/settings are preserved.

Scope: This is a version-specific local release patch, not a complete source
checkout or an upstream rebuild. A future upstream upgrade needs a new patch.
The original DONATE command implementation remains in the binary; the homepage
entry and automatic startup prompt have been removed.
